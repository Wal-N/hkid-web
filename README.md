# HKID Web

Generate sample Hong Kong identity card (HKID) details and check HKID numbers in your browser. Both tools use [**HKID Utilities (`hkid-utils`)**](https://github.com/Wal-N/hkid).

[Open in English](https://wal-n.github.io/hkid-web/) · [開啟繁體中文版](https://wal-n.github.io/hkid-web/zh-hk/)

## Generate a sample

The **Generate** tab opens with a sample HKID number, Chinese and English names, and card details. Select any value to copy it, or select **Regenerate** for another sample. Use generated numbers as test data. A sample may match an issued HKID number.

## Check a number

Open **Validate**, enter an HKID number and select **Check**. A successful check confirms the number’s format and check digit. To calculate a missing digit, enter just the prefix and six digits. For example, `A123456` gives the check digit `3`.

## Privacy and usage statistics

Entered numbers and generated card details stay in your browser. The footer shows estimated visitors and how many samples Google Analytics has counted, including the automatic sample on each page load. The totals refresh daily and may change as recent events are processed.
